# 📦 Install Azure App Service Extension - Step by Step

## 🎯 **Why You Don't See "Deploy to Web App"**

The option only appears **after** you:
1. Install the Azure App Service extension
2. Sign in to Azure

---

## 📋 **Step 1: Install Extension** (2 minutes)

### **Method 1: From Extensions View**

1. **Click Extensions Icon**
   - Look at the left sidebar
   - Click the **Extensions** icon (looks like 4 squares)
   - Or press `Ctrl+Shift+X`

2. **Search for Extension**
   - In the search box at the top, type: `Azure App Service`
   - Look for: **"Azure App Service"** by **Microsoft**
   - It should be the first result

3. **Install**
   - Click the **"Install"** button
   - Wait for installation (30 seconds - 1 minute)
   - You'll see "Installed" when done

### **Method 2: From Marketplace**

1. **Open Extensions**
   - Click Extensions icon (`Ctrl+Shift+X`)

2. **Search**
   - Type: `Azure App Service`

3. **Install**
   - Click "Install" on the Microsoft extension

---

## 📋 **Step 2: Sign In to Azure** (1 minute)

1. **Find Azure Icon**
   - After installation, look at the left sidebar
   - You should see a **blue cloud icon** (Azure icon)
   - Click it

2. **Sign In**
   - Click **"Sign in to Azure..."**
   - Browser will open
   - Sign in with: `ahmed98126@gmail.com`
   - Click "Continue"
   - Authorize VS Code
   - Browser will say "You have signed in to the Azure Account"

3. **Verify**
   - Back in VS Code, you should see your subscription
   - Look for "SUBSCRIPTIONS" in the Azure sidebar
   - You should see your Azure subscription listed

---

## 📋 **Step 3: Deploy** (Now the option will appear!)

1. **Right-Click Project Folder**
   - In the Explorer sidebar, right-click on **"INVOICE-VALIDATOR"** (the root folder)
   - NOT on a file, but on the folder itself

2. **Look for "Deploy to Web App..."**
   - This option should now appear in the context menu
   - Click it

3. **Select App Service**
   - Choose your subscription
   - Select **"Valix"**
   - Deploy!

---

## 🆘 **If You Still Don't See It**

### **Check 1: Extension Installed?**
- Go to Extensions (`Ctrl+Shift+X`)
- Search "Azure App Service"
- Does it say "Installed"? If not, install it

### **Check 2: Signed In?**
- Click Azure icon in sidebar
- Do you see "Sign in to Azure..." or do you see your subscription?
- If you see "Sign in", click it and sign in

### **Check 3: Right Place?**
- Make sure you're right-clicking the **folder** (INVOICE-VALIDATOR)
- Not a file, not empty space, but the folder name itself

### **Check 4: Reload VS Code**
- Press `Ctrl+Shift+P`
- Type: `Reload Window`
- Press Enter
- Try again
